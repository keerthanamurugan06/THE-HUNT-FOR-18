# ROUND 2 – PASSWORD BREAKER

## Overview
Teams solve six independent password and code-breaking challenges.

**Provisional duration:** 15 minutes  
**Status:** Core gameplay confirmed; challenge content pending.

## Gameplay
- Six challenges are available immediately.
- Teams choose their solving order.
- Display order is randomized separately for each team.
- One challenge depends on evidence from Round 1.
- Each correct challenge reveals one hidden word.
- Six hidden words form an investigation-related key phrase.
- Correct phrase submission unlocks the next investigation stage.

## Candidate Challenge Styles
These are suggestions, not finalized content:
- Cipher decoding.
- Number sequence or number-to-letter conversion.
- Hidden message or observation.
- Riddle password.
- Logic clues.
- Evidence-dependent challenge.

## Participant Interface
- Six challenge tiles.
- Challenge status.
- Input and submit controls.
- Attempts remaining.
- Revealed hidden words.
- Phrase builder.
- Round 1 evidence display.
- Autosave and timer.

## Organizer Interface
- Create and edit challenges.
- Configure protected answers.
- Set hidden word per challenge.
- Configure Round 1 dependency.
- Configure attempt limits and scoring.
- Configure the final phrase.
- Manage timer and round activation.

## Confirmed Rules
- Final phrase attempts are unlimited, independently of individual challenge attempt limits.
- No penalty is applied for incorrect final phrase attempts.
- Correct final phrase unlocks the next investigation stage.

## Security
- Keep answer keys server-side.
- Validate answers securely.
- Do not reveal hidden words before successful validation.
- Prevent duplicate scoring.
- Preserve challenge progress after refresh.
